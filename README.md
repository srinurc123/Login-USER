React Authentication Demo
This project is a simple React app demonstrating user registration, login, and profile management with form validation and password visibility toggles.

Features
Register new users with email, phone, and password.

Login with email and password.

Edit user profile (Name and Phone).

Password fields include show/hide functionality.

Responsive styling with Bootstrap and custom galaxy-themed background.

How to run
Install dependencies: npm install

Start development server: npm start

Open browser at http://localhost:3000

This is a frontend-only demo using React state; no backend integration.
